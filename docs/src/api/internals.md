# Internals

This page documents the remaining `GeoDynamo` symbols that carry docstrings but
are not part of the curated public surface on the other reference pages.

!!! note "Removed APIs"
    The older performance-manager and conversion/combination helper APIs are no
    longer part of the supported public surface. The current documented workflow
    is the solver API, the field/transform utilities, and the explicit example
    programs under `examples/`.
